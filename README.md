# Delaware Bill Tracker
Scrapes bill information from legis.delaware.gov and exports a CSV for legislative recap tracking.

## Goal
Input a list of Delaware legislation IDs.
Output a CSV with bill metadata and current action/status: 

Bill Information
- Bill number (e.g. "Senate Bill 65")
- Long title (e.g. "AN ACT TO AMEND TITLE 7 OF ...")
- Synopsis (e.g. " This Act removes Delaware from the Regional Greenhouse Gas...")
- Sponsors (Primary, Additional, and Co-Sponsors)

Status
- Status
- Next Step

Bill Metadata
- Legislation ID
- Bill URL
